# GitHub-Dateien vollständig ersetzen

Dieses Paket ist Version 23 vom 18. September 2026.

1. ZIP-Datei auf dem Computer entpacken.
2. Im GitHub-Repository **Add file → Upload files** öffnen.
3. Sämtliche Dateien und Ordner **aus dem entpackten Paket** in das Upload-Feld ziehen – nicht die ZIP-Datei selbst.
4. Vorhandene Dateien mit gleichen Namen ersetzen und **Commit changes** wählen.
5. Unter **Settings → Pages** prüfen, dass der richtige Branch und der Ordner **/(root)** ausgewählt sind.
6. Nach der Veröffentlichung die Seite einmal vollständig schließen und neu öffnen.

Kontrolle: Das Anfrageformular sendet an Formspree `xyezyrjy`, die Datenschutzseite nennt Formspree und Portal24, und alle Seiten laden `styles.css?v=23`.
